# Changelog

## 1.0.0 — 2026-11-03

Completed local acceptance and deployment preparation for the six development phases. Added tab-scoped writing recovery, explicit idempotency-conflict handling, account/request boundaries for async results, a rendering error boundary, bounded feedback request streaming, strict-CSP validation, production smoke tests, clean-install checks, generated content verification, Windows startup script, dependency license notices and a hardened CI workflow.

Security updates: React Router 7, Zod 4, Vitest 5, ESLint 10 and patched minimatch override. Node.js 24 LTS is recommended. The audit snapshot reports zero known vulnerabilities; hosted Supabase, external AI, remote GitHub CI and public deployment remain unverified and unconfigured.

Earlier Phase 1–5 guides and source archives are retained as development history.

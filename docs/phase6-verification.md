## 本轮修复

- 写作自动保存前快捷返回/重新加载导致末尾文字丢失：按用户、作文和标签页保存恢复缓冲，确认保存后清除，保留冲突版本供导出与合并。
- UUID 幂等冲突被 UI 恢复逻辑当成成功：practice/vocabulary 明确保留 IDEMPOTENCY_CONFLICT；真正网络中断后，已确认的相同请求仍能恢复成功。
- 较旧异步结果覆盖新记录或出现在切换后的账号中：分析请求使用版本和账号边界，写作拒绝较旧时间戳快照。
- 渲染异常导致空白页：新增不清除数据的错误边界与重载入口。
- 可选 AI 请求体的资源限制：在流读取时限制为 2 KB，不先无界读取整个请求。
- 依赖升级：React Router 7、Zod 4、Vitest 5 与 ESLint 10，保留 React 18/Vite 6；适配表单的输入/输出类型与顺序数据库测试。minimatch 11 安全覆盖在实际 lint、类型检查、内容生成、全部测试和干净安装中验证。
- 严格 CSP 下 Zod 动态生成探测触发违规：统一 validation 入口，在构造应用 schema 前启用 jitless，没有放宽为 unsafe-eval。
- Windows 测试服务停机挂起：改用 Vite API 和交付的静态服务在测试进程内管理服务，不依赖终止 shell 进程树。

构建成功；上游 Zod 的两处 PURE 注释会被 Rollup 提示并移除，属于注释位置警告，不影响运行，也未屏蔽这些提示。干净安装可能提示 whatwg-encoding 的弃用信息，这是测试依赖，不是当日审计漏洞。

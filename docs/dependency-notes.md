# Dependency maintenance

2026-11-03 release: Node.js 24 LTS recommended; React 18 and Vite 6 remain. React Router was upgraded to 7.18.5, Zod to 4.6.7, Vitest to 5.1.0, and ESLint to 10.14.0 with current compatible form resolver and TypeScript ESLint packages. package-lock.json pins the actual installed tree.

The minimatch ^11.0.1 override addresses [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249), which also affected the latest lint dependency ranges available during this release. The override was verified using actual lint, type checking, content generation, all tests and a fresh npm ci. Do not use audit fix --force to downgrade ESLint blindly; remove the override only after upstream ranges resolve to a patched version and verification passes.

Zod uses the shared src/lib/validation.ts entry with jitless enabled before schemas are created, so the strict CSP does not require unsafe-eval. See [Zod CSP guidance](https://zod.dev/compile). The form resolver distinguishes schema input and transformed output types. Vitest database suites execute sequentially through explicit configuration, following [Vitest migration guidance](https://vitest.dev/guide/migration/).

Production license texts are generated by scripts/generate-notices.mjs from locked installed packages into public/third-party-notices.txt. npm run build refreshes them. Project code is MIT; third-party packages retain their own notices and licenses.

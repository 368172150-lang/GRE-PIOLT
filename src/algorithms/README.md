Pure TypeScript modules implement calendar/streaks (dates), budgeted daily tasks (planner/study), SM-2 and vocabulary state (sm2/vocabulary), CSV parsing, exact rational/choice grading, practice transitions, writing transitions, real-data analytics and explainable recommendations. Explicit inputs and instants make date boundaries testable. SQL RPC parity, 360 SM-2 combinations and five real migrations are exercised with PGlite. See docs/learning-algorithm.md for rules and limitations.
